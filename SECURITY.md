# Security and Privacy Policy

This repository is public. Do not post secrets or private operational details in issues,
pull requests, discussions, screenshots, benchmark logs, or attachments.

## Do Not Post

- API keys, tokens, passwords, private keys, or credentials.
- Participant data, payment data, banking details, labels, or shipping records.
- Supplier pricing, supplier records, private procurement records, or private
  operational notes.
- Private hostnames, private IPs, home-directory paths, private logs, or unredacted
  screenshots.
- Legal filing documents, filing screenshots, addresses, or tax identifiers.

## Reporting Security Or Privacy Issues

If GitHub private vulnerability reporting is enabled for this repository, use it for
security or privacy-sensitive reports.

If private vulnerability reporting is not available, open a public issue with only a
brief non-sensitive summary and ask maintainers to establish a private channel. Do not
include exploit details, secrets, private data, logs, screenshots, or operational
records in the public issue.

## Benchmark Report Safety

Benchmark reports must not include sensitive data. Remove secrets, local paths,
usernames, private network details, private infrastructure names, participant data,
payment data, supplier details, and unredacted screenshots.

## Redaction Guidance

Before sharing logs or screenshots:

- Remove tokens, keys, cookies, and credentials.
- Remove private hostnames, private IPs, home-directory paths, usernames, and local
  network details.
- Remove participant, payment, supplier, and shipping information.
- Remove legal filing details and tax identifiers.

When in doubt, do not attach the file publicly.
