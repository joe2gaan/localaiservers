# Title

Review funding and donation-boundary documentation

## Context

The repo includes funding and program-boundary docs that separate charitable donations
from hardware verification, pass-through costs, and fulfillment. Human review should
confirm that the language is accurate for public use.

## Desired Outcome

Review `docs/funding.md`, `docs/program-boundaries.md`, README funding text,
`.github/FUNDING.yml.example`, and communication templates for clarity and boundary
consistency. If an active `.github/FUNDING.yml` is later enabled, review it before
committing.

## Acceptance Criteria

- Confirms the donation placeholder is still a placeholder unless a reviewed public
  donation page is ready.
- Confirms donations are not described as providing hardware, priority access,
  discounts, program participation, or private benefits.
- Confirms program payments for hardware verification, pass-through costs, or
  fulfillment are described as separate from donations.
- Identifies any wording that needs legal, accounting, or board review.

## Suggested Labels

`documentation`, `funding`, `human-review`

## Difficulty

Intermediate

## Privacy Reminder

Do not add payment links, routing details, account details, filing documents, addresses,
tax identifiers, participant data, or private operational records.
