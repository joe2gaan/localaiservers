# Support

Support is best-effort through GitHub Issues.

## Scope

This repository supports public documentation, reproducibility reports, benchmark
reports, QC methodology, and source-level GFX906 issue discussion.

## Boundaries

- This is not a public cloud service.
- This is not public remote compute.
- This repository does not provide direct machine access.
- This repository does not provide hardware warranty or resale support.
- Do not post secrets, private logs, private paths, payment details, supplier details,
  or participant data in support requests.

## Best Issue Types

- Documentation correction.
- Reproducibility report.
- Benchmark report.
- Hardware QC methodology improvement.
- Source-level GFX906 runtime issue.
